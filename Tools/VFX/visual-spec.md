# 技能视觉说明书

本规范依据本工程已完成的爆炸、符箓命中与落雷制作。每个新任务使用 [任务单](Templates/visual-brief.md) 留下具体参数；不能只提交“更炫”“更有冲击”这样的形容。

## 视觉语言

明快卡通、简洁手绘块面、清楚的外轮廓，与游戏实际战斗镜头一致。浅沙地图需要饱和主体和较深轮廓，亮芯只占小部分，外围留空；不要依靠大面积白光或浅色烟雾制造力量。先按实际显示尺寸观察，再看放大图。

| 类型 | 已验证的方向 | 后续变化方式 |
| --- | --- | --- |
| 普通爆炸 | 橙金小亮芯、深橙红主体、棕灰烟团 | 圆润冲击、尖锐星芒、穿刺轮廓、厚重断环分别表达不同武器 |
| 符箓 | 金色符面、朱红符纹与深色边缘 | 命中印记小而集中，碎光有限；飞行纸符与命中分开设计 |
| 普通落雷 | 白青细芯、紫蓝电弧 | 主雷迅速击中，落点余电单独一层 |
| 突破落雷 | 朱红、绯红主体，细暖白芯、深红边缘 | 使用专用分叉形状与落点电弧；以红色为主，不继续叠加蓝色主雷 |
| 罡气护体 | 普通绿色 / 突破橙金，通透覆盖、三层六边形与内外反向旋转弧 | 突破增加 1.7 倍带宽、金白长弧与六枚能量棱角，旋转提速 45%；传播时间为原视觉周期 × 1.6，真实范围和伤害 Tick 不变 |
| 刀光剑影 | 普通银白青锋、青蓝刃与深蓝轮廓；满级金青双刃 | 主体轮廓区分等级，短柔边剑气连接运动，实际命中播放集中交错切痕；环绕与分裂复用对应飞刃，文字保持可读 |
| Boss 刀气爆发 | 橙红短刀气、深红轮廓、小面积暖白芯 | 原蓄力阶段按真实 8 / 12 / 16 向显示刀影与收束环；释放短环、柔边尾迹、命中 / 到期小消散，保留可穿行间隙 |
| Boss 冲刺 | 低透明朱红胶囊路径、深红边与方向箭头 | 覆盖身体包络，跟随玩家至原 0.3 秒末才锁向；整段路线在冲刺时淡化保留，速度线从字形后沿绘制，终点短双环 |
| Boss 小刀 | 紧凑朱红短刃、深红边、小暖白芯 | 字形前沿即时出手闪、0.08 秒柔边短尾、命中玩家 / 到期小消散；复用刀气图集，保持实际直飞 |

文字怪和危险提示必须可辨认。当前玩家一次性命中特效沿用排序 `-5`，处于文字与角色下方；Boss 刀气预警 / 消散为 `4`、短尾 `9`、伤害弹体 `10`，分别在真实战斗中检查。新层级须结合实际场景核对。工作台文字只是对照示意，不能替代实际 TMP 怪物文字检查。

## 事件与时序

先标明真实伤害发生在哪一个事件。已在碰撞 / 爆炸 / 落雷处结算的技能，第一帧就应进入冲击；蓄力只能挂到技能本来存在的释放前阶段。动画完成不负责结算伤害，也不改变冷却、连发间隔、索敌或碰撞半径。

Boss 冲刺的路线覆盖 `max(技能检测半径, 世界身体半径)`，不能把原 1.2 技能查询半径当作更大身体的全部危险宽度。路线跟随 / 锁定时机和墙体截断要与真实模块分别核对；当前 4-contact Cast 在拥挤碰撞下有原预判上限。小刀视觉出手闪可取 TMP 前沿，真实弹体仍在 Boss 位置即时生成；表中预留追踪参数不等于已经生效。当前冲刺 / 小刀样本保留原单次 OverlapCircle 和 turnRate=0，验收必须记录真实结果，不能把 AI 接触伤害当作冲刺技能伤害或把 Trigger 的 wallMask 当作已验证的墙体碰撞。见[制作记录与边界](boss-dash-knife-v1.md)。

文字怪的贴身命中点使用可见字符几何，不能直接把固定 Collider 边缘当字面。符箓和飞刃的短命中烙印跟随字块，暂停、死亡和池复用须正确解除；雷击、导弹和射线可修正视觉坐标，原伤害中心独立保留。手雷落地和随机余爆维持真实爆点。入口与验收见 [命中落点修订](hit-feedback-alignment-v1.md)。

一次性图集发射 1 颗粒子，`Duration = Start Lifetime = 配方层时长`，单次播放、零速度、零延迟。帧序使用 Lifetime 曲线，`simulationSpeed=1`。回池时间至少覆盖最长一层寿命并留余量；本批效果同步延长了播放和回池。只改 `Duration` 不足以延长粒子的实际动画。

配置库保存最终秒数。每次改时长，应同时核对帧曲线、透明度、回池和同屏重叠数量。现有两层落雷同时开始，两层时长不相加。突破、回响与逐道落雷的触发规则由原技能代码控制。

## 图集、锚点与透明度

- 顺序统一为从左到右、从上到下，索引从 0 开始。源图行列与正式图集行列分别记录；8 帧、16 帧按动作需要选用，不把 4×4 当硬标准。
- 原稿镜头、中心和尺度基准一致。常规命中以中心为锚点；落雷需额外标明接触尖端在单格中的比例，并通过层的本地位置对齐落点。不要让图案中心漂移来模拟扩张。
- 原稿建议每格预留 10%–15% 透明边距；打包器可另加透明像素边界。Clamp 只能处理整张纹理边界，不能修复格内跨帧串色。
- 默认交付真实 RGBA，使用已存在的 `Sprites/Default`。在浅、深底检查黑边、白边、半透明碎屑与末帧。棋盘格只能作为预览底，不能画进 PNG。
- 当前工具只处理普通透明、白色粒子、固定单粒子图集层。黑底能量 / 加法混合、特殊 Shader、非均匀时间延迟、多循环段需单独设计并验收，不能直接套此导入器。
- 原始源图保留在 Assets 外；只导入选中、缩小、打包后的运行图。导入工具不会删除背景、重绘轮廓或生成中间帧。

## 资源预算

| 级别 | 起点 | 升级条件 |
| --- | --- | --- |
| 高频小命中 | 1 层、8 帧，优先 64 像素级单格 | 实际战斗尺寸下仍无法表达主体才增加精度 |
| 常规爆炸 | 1 层、8 帧，优先共享 1024×512 内的图集 | 新武器需新的轮廓时再占新帧段 |
| 普通落雷 | 2 层、每层 8 帧，共用 512×256 | 优先保持文字可读与分叉结构 |
| 低频突破 | 2 层、每层 8 帧，最高优先试 1024×512 | 专用美术与清晰度收益经对照确认；突破不等于无限叠层 |
| Boss 刀气 | 共享 512×256，单 Mesh 预警、每发 1 Sprite + 1 Trail、单层 8 帧小消散 | 优先复用敌方刃形和无贴图网格；不以装饰限流删除真实危险提示 |
| Boss 冲刺 / 小刀 | 本轮 0 新 PNG、Texture、材质；各单 Mesh 表现，小刀 1 Sprite + 1 Trail | 复用 28,653 字节 Boss 图集、实体 / 柔边材质和消散，缩放视觉子级，不缩放弹体物理根 |
| Boss 分身 | 0 新 PNG / Texture / 材质；每角色 1 身份网格，蓄力重影每字体 atlas 2 个复用网格 | TMP 与装饰透明度统一；本体实印、分身断续印；字体材质共享，危险预警与弹体保持完整 |

分身先验证真实 Start 和后续模块重建的白名单，再调视觉。克隆不得继承分身 / 复活、复制本体池身份或增加胜利 / 杀敌进度；要分开验收本体假死、真死、回池、分身自然到期与自身禁用。角色半透明只作用于角色文字和装饰，不能降低真实攻击预警或弹体的透明度。[分身 V1](boss-clone-v1.md)留有实际生成和两轮重叠证据。

Boss 常驻身份标记避免复用伤害弹体造型。当前[紧凑头标](boss-head-crest-v1.md)跟随可见字形顶部，支持显式头部节点和身体渲染器绑定；切换 Spine 主体时需同时迁移出手、命中、后沿、分身重影与退场表现，不能只隐藏 TMP 就视为完成。

召唤标记使用真实成功出生后的位置，须在地图约束、竞技场 clamp、卡墙推出与文字绑定完成后回调。不预抽样坐标、不显示失败出生的空门、不推迟碰撞或改变怪物透明度；施法者回池后用令牌丢弃旧批次视觉回调，已经释放的波次保持原生成规则。参见[召唤 V1](boss-summon-v1.md)。

复活散字和回聚使用同一份实际字形快照，并保留 UV / UV2、渐变和共享字体材质；身体隐藏期间单独显示所属核心。恢复弹动不能缩放物理根节点。保护弧必须核对真实伤害探针和实际盾寿命，回池 / 重建须取消旧复活与旧免伤，见[复活 V1](boss-revive-v1.md)。

这些是本项目的制作起点，不是微信硬件上限。正式 PNG 上限按任务填写；现有库分别为符箓 / 刀光剑影 / Boss 刀气 96 KiB、普通落雷 128 KiB、红色突破 256 KiB、四款共用爆炸图集 512 KiB。复用图集按纹理路径去重统计。

WebGL 使用 ETC2_RGBA8Crunched，关闭 mipmap / Read-Write，Clamp / Bilinear。ETC2 RGBA8 无 mipmap 块数据按 `ceil(width/4) × ceil(height/4) × 16` 字节估算；PNG 压缩大小不是显存。对象池减少创建销毁，但不消除透明过绘。持续时间或层数增加后，要重新记录重叠峰值。

玩家装饰效果继续通过 CombatVfx 限流，当前基线为每帧 8 个、同时 32 个实例；这不是粒子数上限。限流只能省略表现，不能取消原伤害。Boss 方向预警与真实伤害弹体必须完整显示，不进入这项装饰限流；刀气的小消散可以限流，借出与回池继续走现有池化入口。多 Boss / 分身压力应分别记录全部危险方向与弹体数量，不能只观察装饰粒子峰值。
