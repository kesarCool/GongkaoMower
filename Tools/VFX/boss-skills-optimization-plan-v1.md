## 当前实际配置

- BossBrain 支持 **8 类技能模块**；当前 Monster Boss 配置使用 **6 类**，未使用 `zone` 和 `resist`。
- Monster 表共 **36 条 Boss 配置**；当前关卡表引用 **35 个 Boss / 35 条 Boss 波次**。33061「真假难辨」在 Monster 表中存在，目前未被 Boss 波次引用，也未登记到当前 EnemyCatalog。
- 当前 EnemyCatalog 的 **35 个 Boss 共用 boss_common.prefab**。因此升级共享技能模块即可覆盖多数 Boss，不需要为每个名字制作一套独立特效。

## 先解决的基础问题

刀气、冲刺与小刀已通过独立表现入口处理真实方向、释放阶段、中断取消与尾迹清理，并完成与 8 / 16 向刀气的组合回放；下列统一 TMP 状态、多技能状态恢复和其他模块疑点仍属于后续工作，不能视为首批样本已经覆盖全部模块。

**文字要能表达蓄力和状态。** `BossSkillModule.CacheSprites/SetSpritesFlash` 只操作 SpriteRenderer，Boss 主体是 TMP。分身 V1 已用独立组件处理字形重影、文字 / 装饰透明度与身份标识；召唤 V1 使用跟随实际文字中心的脚下符环表达蓄力；持续护盾等仍需后续处理。保留中文字形和共享字体材质，避免每次施法创建新字体材质。

**视觉锚点分用途。** 出手闪点、字块状态、复活核心跟随文字可见中心；飞行弹体的图形对齐自身 Collider；冲刺路径、地裂、召唤落点使用实际世界位置和碰撞范围。不能把所有危险范围都吸附到文字中心。此前玩家命中贴字的改法只适合对应的接触表现。

1. **共用入口与校准**：统一 TMP / 装饰状态表现、攻击阶段与取消入口、坐标和尺寸规则，建立小刀 / 冲刺 / 刀气的修改前真实回放。分身继承问题单独复现和修正。地裂、护盾未启用，先记录接入阻塞项，不抢占首批美术制作。
2. **第一批：刀气爆发 → 冲刺 → 小刀，已完成首轮表现**。刀气覆盖 23 条、冲刺 18 条、小刀 13 条 Boss 配置；冲刺与小刀复用刀气资源，79 项实战覆盖单技能、15 / 20 速度、墙边 / 地图边缘、暂停、取消、回池首个物理步，以及 8 / 16 向刀气组合。刀气历史 89 项另含手动多施法者并发。真实分身继承后由第二批单独修正；小刀追踪与冲刺原单次伤害查询仍保留各自边界。
3. **第二批：分身 → 召唤 → 复活，逐项验收**。分身 V1 已完成真实继承与真伪识别；召唤 V1 已接入源符环和真实出生点门印；复活 V1 已接入实际字形回聚、核心和真实保护弧。第二批现有技能已完成。地裂 V1 已完成能力与预览，尚未修改正式表；免伤护盾模块继续保留后续。
4. **第三批：地裂与免伤护盾**。地裂 V1 已完成机制校准、独立表现和四份 Boss 组件接入；免伤护盾尚待制作。启用新技能及改变追踪、预警、锁向时间均另记平衡结果。

## 资源与运行预算建议

- 首批共用 **一张 512×256 Boss 图集，源 PNG 28,653 字节，预算 ≤96 KiB**，容纳敌方刀形与 8 帧小消散；3 份共享材质。刀气预警为单 Mesh 两个 submesh，冲刺路径和小刀出手闪各单 Mesh；新增冲刺 / 小刀为 0 新 PNG / Texture / 材质。ETC2 RGBA8 无 mipmap 块数据为 128 KiB；这些是资源指标，不是最终微信包体。
- 地面圈、箭头带、护盾尽量复用网格；复活继续用现有字体。材质尽量控制为 2–3 个共享实例，关闭正式纹理 mipmap 和 CPU 可读副本。
- 清理每次施法 `new Texture2D/Sprite.Create` 的路径，改成共享缓存 / 图集。旧代码多处只销毁 GameObject，没有显式释放新建的原生纹理 / Sprite；长局需做内存复测，不能只看 PNG 大小。
- 池化弹体、短反馈、圈与字块；相同材质共用，尾迹短。Shader 优先复用既有实现，不先引入新渲染管线或大面积后处理。
- 当前分身每 10 秒施放、存活 15 秒，存在两轮重叠窗口。刀气历史夹具的手动 CloneMarker 样本只承担压力验证；后续分身 V1 已真实生成两轮，峰值 4 个，并保留 24 个实际预警方向 / 24 发弹体及自然到期回放。继承修复的证据使用分身独立报告，不能沿用旧手动压力结论。
- **危险预警和真实伤害弹体不能套用玩家装饰 VFX 的每帧 8 / 同屏 32 限流。** 圈、路线和弹体轮廓必须可靠显示；可限流的是碎屑、尘环、亮点和外层光。分身施放技能时也遵守这一规则。

## 实施后的验收

每批先单技能、再多技能组合，保留实际时间的前后回放。检查浅沙 / 草地 / 深底、字体随机角度和大小、移动与转向、近身、墙边、暂停和恢复、死亡、Boss 回池、复活、中断与退场。

危险带和圆圈必须核对世界位置、真实范围、锁定时机和伤害时刻；发射数量、速度、伤害、索敌、冷却与有效射程分别留记录。分身单独核对继承白名单、本体死亡清理、复活限制和胜利判断；召唤核对真实出生点；护盾核对减伤与耗次。持续多轮战斗后观察对象、材质、纹理是否增长。最后用相同微信机型和关卡测帧时与构建增量，Editor 结果不能替代真机结论。
