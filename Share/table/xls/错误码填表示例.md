# c错误码c.xls 填表示例

与 `ErrorCodeTable.fbs` 列一致。导出后生成 `Assets/Resources/Data/table_fb/ErrorCodeTable.bytes`。

## CodeDisplay

| 值 | 含义 |
|----|------|
| 0 | 不弹 UI，仅 `Debug.Log`（程序/配置类建议） |
| 1 | Toast（`UIManager.toastPanelPrefab`） |
| 2 | 对话框（复用 `PopConfirmPanel`，单按钮「知道了」） |

## Unity 配置

1. 导出 `ErrorCodeTable.bytes` 后确认 `TableManager` 已包含该表（已注册）。
2. `Home` 场景 `UIManager`：`confirmDialogPrefab` = PopConfirmPanel；`toastPanelPrefab` = **需新建**（见下）。
3. Toast 预制体：复制一条横条 UI，挂 `UiToastPanel`，子节点 TMP 绑到 `messageText`，拖到 UIManager。

## 代码调用
