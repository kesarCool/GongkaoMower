# 地图设计方案

## 关卡-地图映射

```
第一章（入门）
  101-102 → Map_Ch1_A（小型，40×35）    新手引导，面积最小
  103     → Map_Ch1_B（小型，42×38）    稍微扩大
  104-105 → Map_Ch1_C（中型，48×42）    Boss 关，略微复杂

第二章（进阶）
  201-202 → Map_Ch2_A（中型，46×46）    正方形竞技场
  203-204 → Map_Ch2_B（中型，50×44）    变体形状
  205     → Map_Ch2_C（中大型，52×50）  Boss 关

第三章（挑战）
  301-302 → Map_Ch3_A（中大型，52×48）
  303-304 → Map_Ch3_B（中大型，54×50）
  305     → Map_Ch3_C（大型，58×54）    Boss 关，最大面积
```

## 设计原则

- **面积递增**：第一章最小（40×35=1400 格），第三章最大（58×54=3132 格）
- **形状各异**：矩形、正方形、不规则十字、环形、菱形
- **内部差异**：墙壁布局不同——有的空旷（割草爽），有的有障碍（走位考验）
- **中文命名**：每张图有名字，方便记忆
