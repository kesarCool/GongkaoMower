# 《文字割草机》考公方向：首章内容设计 v1

日期：2026-10-11。状态：可评审的内容原型，尚未接入 Unity。下文的时长、数值、奖励与文案均为设计提案，不代表已上线配置，也不保证改善留存。

## 1. 产品体验

面向想在备考间隙玩一小局的考公人群，提供“打完一局，回忆一个知识点”的体验。画面采用已选定的明快卡通方向：奶油色面板、深色描边、橙黄色主按钮、绿色选中反馈。保留持枪角色、文字怪、瓦片地图和现有战斗技能。

第一版聚焦数量关系的基础行程问题。先完成一个主题的完整体验，再扩展工程、利润等公式和常识。不立即铺开五个角色的新定位、大题库和新的养成系统。

玩家循环：进入主题关卡 → 移动与自动射击 → 升级形成技能组合 → 击败知识精英/关底怪 → 领取战斗奖励 → 可选做一道回忆题 → 下一关或退出。

体验目标：首局很快看到击杀、技能变化和战斗结算。是否愿意继续，以及是否记住知识点，需要分别验证。

## 2. 首局：路程入门，45 秒战斗

以下按战斗计时计算，选卡暂停不计入。真实体验时间还包含加载、阅读和选择；验收时必须另外用秒表记录，不能把 45 秒战斗当成 45 秒总流程。

| 时间 | 玩家看到/做什么 | 设计作用 |
|---|---|---|
| 进入前 | 已选持枪角色；主按钮“开始闯关”；副文案“路程入门 · 45秒挑战” | 不先要求配装、升级角色、签到或阅读教程 |
| 0—3 秒 | 地面短提示“拖动移动，自动射击”；附近两三个弱怪“路程”“速度” | 立即可以移动和击杀；提示随首次移动消失 |
| 3—8 秒 | 小群文字怪从两侧靠近；经验自然掉在行进路线上 | 引出经验与第一次升级 |
| 约 8 秒 | 第一次三选一：枪械强化 / 环绕飞刀 / 手雷 | 新手推荐环绕飞刀，但玩家仍可自由选；只用战斗收益文案 |
| 8—22 秒 | 密度提高，飞刀或手雷产生可见的清怪变化 | 技能升级必须改变数量、范围或节奏，不能只涨隐蔽数值 |
| 约 22 秒 | 第二次三选一；出现较大的知识精英“时间” | 引出另一项技能或升级；精英沿用普通敌人底层，只改文字、尺寸、血量与描边 |
| 22—35 秒 | 击败精英，飘出“知识卡已收集”，不弹窗 | 让玩家知道结算有收获，不额外中断战斗 |
| 36—45 秒 | 关底怪“题海怪”出现；击败后提前结束；到时自动结束并按现有生存规则结算 | 给短局明确终点。第一关目标是完成体验，避免难度突然陡增 |
| 结算 | 先展示战斗结果和基础奖励，两个入口：“回忆一道题”“下一关” | 战斗奖励不依赖答题；退出也不丢已获得奖励 |

首局保底：第一个升级前不安排难躲的冲刺怪。前两次选卡提供至少一种有明显外观变化的选项。若经验收集慢导致未升级，可做首局专用保底；正式规则需要接入后验证，不能在所有关卡硬按秒弹卡。

首局死亡：正常结算已获得内容，提供“一键再试”，不要求先观看广告或进入复杂养成页。不因死亡自动弹答题。

## 3. 首章五关

| 关卡 | 名称 / 主要知识 | 战斗时长提案 | 地图复用 | 战斗变化与结算题 |
|---|---|---:|---|---|
| 1-1 | 路程入门：路程＝速度×时间 | 45 秒 | 演武场 | 稀疏怪→两侧小群→关底怪；题目只求路程 |
| 1-2 | 单位关：先统一单位 | 60 秒 | 演武场 | 普通怪混入“小时”“分钟”；结算题检验 km/h 与分钟换算 |
| 1-3 | 相遇关：相向用速度和 | 60 秒 | 石林阵 | 两侧出怪、中央汇合；是视觉联想，不把怪物运动当作真实数学模拟 |
| 1-4 | 追及关：同向用速度差 | 60 秒 | 四合院 | 慢怪聚集，少量快怪跟进；快怪速度先保守，保留可走开的空隙 |
| 1-5 | 题海突围：判断用哪条关系 | 75 秒 | 四合院 | 三段复用前面刷怪组合；关底怪放大并加血条。结算随机一道已学概念变式，不连续强制五题 |

表内 1-1 至 1-5 是新主题内部的展示序号，不是对现有美食篇关卡 ID 的覆盖。地图可复用，正式关卡和词条必须分配新的唯一 ID，保留旧篇章与旧存档。具体接入见同目录《考公内容_现有工程接入方案v1.md》。第 2—4 关的升级目标为战斗约 10/25/40 秒附近，仍由经验触发；第 5 关允许更多一次升级。先用密度和已有敌人类型改变节奏，避免新增长文案怪、贴图和复杂 AI。

## 4. 文字怪怎么承载主题

移动中的文字只放短词，首章建议控制在“路程、速度、时间、小时、分钟、相向、同向、间距、速度和、速度差”等 2—3 字词。长度更长的完整公式放在知识卡，不要求玩家在战斗中阅读。

怪物分三种表现，复用同一个文字渲染体系：

- 普通怪：短词、小尺寸、统一描边；血量少，让玩家连杀。
- 精英怪：同一字体，稍大，外加色块/描边与血条；掉落知识卡标记。颜色和尺寸同时区分，不能只靠颜色。
- 关底怪：显示短名字“题海怪”，沿用已有 Boss 模板；常驻血条和一个容易辨认的攻击预告。已有模板不能支持时，先做高血量精英，不另外开发复杂 Boss。

击杀词语只算“接触了主题”，不算“学会了公式”。词语与怪物行为可以提供联想，但不会替代条件、单位和题目练习。

## 5. 技能仍然负责爽感

第一版优先开放枪械、环绕飞刀、手雷与少量现有被动。沿用项目真实技能名与参数；下面是文案结构示例，不能直接当作现有数值。

| 选卡 | 主文案 | 收益行示例 | 画面要求 |
|---|---|---|---|
| 枪械强化 | 自动射击更密集 | 弹丸数量 1 → 2 | 出弹数量肉眼可见；若技能不支持多发，则选已有支持的升级效果 |
| 环绕飞刀 | 清理贴近的文字怪 | 飞刀数量 2 → 3 | 选完就出现新增飞刀 |
| 手雷 | 炸开成群文字怪 | 解锁范围爆炸 | 范围圈短暂显现，爆炸后怪物明显减少 |
| 被动升级 | 一句话说明收益 | 攻击 +10%（示例） | 不把无法感知的数值作为首局唯一选项 |

不要把“相遇公式”伪装成一种攻击技能，也不要为了主题强行重命名全部技能。公式不会因为枪械伤害提高而变正确。考公主题主要落在关卡名称、文字怪和战后知识内容。

## 6. 知识卡与回忆题

结算先给基础奖励；回忆题是独立入口，每局至多主动提供一道。玩家选择答题后，先看到题目；提交答案后再展开公式、适用条件与解析。不能先常驻正确公式，再把立即照抄称为“回忆正确”。另设“先看知识卡”，走此入口后答对记为“看过解析”，不计独立回忆正确。

示例：

> 两人沿同一直线同向匀速前进。前者在前方 120 米，速度为 50 米/分钟；后者速度为 80 米/分钟。后者几分钟追上前者？
>
> 选项：2 / 4 / 6 分钟。正确答案：4 分钟。
>
> 解析：每分钟缩短 80−50＝30 米，追及时间＝120÷30＝4 分钟。
>
> 条件：同向、同一直线、匀速、后者速度更快；起始间距与速度单位匹配。

正确反馈：“这道答对了：同向追及用速度差。”按钮“下一关”。不显示“已精通行程问题”。

错误反馈：“这道需要用速度差。每分钟缩短30米，120÷30＝4分钟。”显示原选项与正确项；按钮“换一道试试”和“继续闯关”。不扣血、不撤回战斗奖励、不把答错展示成战斗失败。

状态分别保存：

- 战斗：未通关 / 已通关；使用现有进度。
- 知识：接触过 / 待复习 / 独立回忆正确。看过解析后的重答不累加独立回忆次数。
- 下一次进入同主题，可用不同数字或情境的一道题复习。首版只做本地轮换，不声称已建立完整的间隔复习系统。

知识簿显示知识点、公式、条件、上次回忆状态和“再试一道”。禁止以击杀次数直接生成掌握率或以一次答对生成熟练度百分比。

## 7. 首批题目

题目原型见同目录 `考公首章题目原型v1.json`。共 12 道，覆盖路程、单位、相遇、追及与条件判断。题目必须有条件、单位、正确项与针对错误选项的解释，避免只有公式口号。

数学内容采用以下限定：

- 路程关系：对应时间内速度不变；s＝v×t，单位一致。
- 相遇关系：两人同一直线相向匀速运动，初始间距为 s；t＝s/(v₁+v₂)。
- 追及关系：两人同一直线同向匀速运动，追赶者在后且更快；t＝间距/(后者速度−前者速度)。
- 不覆盖圆形跑道、多次相遇、变速、停留、折返等变式。这些需要单独设计题目与条件。

题目是内容评审数据，不是现有 FlatBuffers 表格式。接入时按项目表工具生成配置，不能修改生成的 ProtoTable 类来硬塞内容。

## 8. UI 内容与层级

首页：顶部低权重显示资源与设置；中间“数量关系 · 行程入门”、当前角色、下一关知识主题；主按钮“开始闯关”；底部三个入口“闯关 / 角色 / 知识簿”。新手入口直接进入第一关，减少首次选择负担。

战斗 HUD：血量、经验、时间与技能；主题只保留短标签“路程入门”。暂不常驻整段知识点、题目或背诵进度。

选卡：三个横向大卡片，技能图标、技能名、升级类型、变化前后数值；点击选中后确认。复用现有选卡暂停；不在这个弹窗塞一段公式教程。

结算：优先战斗成功/失败与基础奖励。第二块是“本局知识：路程与速度”，提供一道题和继续挑战；不要一次叠加奖励弹窗、知识弹窗、题目弹窗、签到弹窗。

知识簿：一个主题列表加可展开详情，不新增第二套卡牌收集养成。使用现有字体与共用面板。

## 9. 包体与工程落点

资源约束：复用瓦片地图、主角和已有技能。首版共用一张 UI 图集中的九宫格面板、按钮、选中框及少量图标；优先复用已有图标。不新增整屏背景、五角色重绘、视频和新的整套中文字体。具体增量以 Unity 构建后差值为准，文本数据小不代表字体图集和材质没有成本。

可利用的现有接口：

- `LexiconTable` 已有 `DisplayText / ThemePackId / CategoryTag / Weight / EffectId`，适合组织主题词库；实际源表位置为 `Share/table/xls/c词汇表c.xls`，修改源表后生成。
- `LevelWave` 已有波次、起始时间、间隔、总量、敌人属性与 Boss 字段，可以尝试配置上述短局；具体参数需要结合现有怪物强度。
- `CardSelectionSystem` 已有选卡暂停、刷新流程，先更换呈现和首局候选池，不重做整套系统。
- 战斗进度沿用现有存档；知识进度独立保存知识 ID、是否看过解析、最近题目 ID、独立回忆结果，避免影响现有关卡通关记录。

开发顺序：先做 1-1 完整流程 → 再配置 1-2 至 1-5 → 最后做知识簿与本地复习轮换。内容评审通过前，不把这份原型覆盖到现有正式关卡。

## 10. 验证这版设计

先找少量正在备考的人做观察式试玩，不要求先接数据平台；这只能发现明显问题，不能证明总体留存改善。

现场记录：首次移动/击杀时间、首次选卡时间、是否看懂强化收益、到结算的真实总时间、是否主动进入下一关、是否主动点回忆题。先让玩家自己操作，不提前解释完整玩法。

学习验证：选一道未展示解析的同类变式，观察是否能说出适用条件并算对；下一次试玩再换题。答对原题、背出公式和能够应用是不同证据。

首局可评审标准：进入后很快能操作；升级前后画面有明显变化；卡片不需要来回寻找关键数值；结算奖励与题目入口清楚；跳过题目仍能继续；答错也能看懂原因。若这些还没达成，先改首局，再扩充题库。

下一主题候选：工程问题。常识后续可按地理、科学、历史分小包；每条建立来源和审核记录。法律、时政等易变化内容另加版本日期，维护能力不足时暂不上线。
