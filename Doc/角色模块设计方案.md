# 人物角色模块设计方案

## 现状分析

### 当前角色系统

| 维度 | 现状 |
|------|------|
| 角色外观 | 单张静态 Sprite，挂在 Player/Body 子节点上 |
| 动画 | 无 Spine、无精灵表动画、无 Animator |
| 武器视觉 | 不存在，子弹从 `transform.position`（玩家根节点）发射 |
| 朝向 | `PlayerController.LateUpdate` 控制 `bodyRenderer.flipX` |
| 受击反馈 | `PlayerHitFeedback`（Body 子节点），做闪红+缩放震击 |
| 技能 | 6 个技能（AutoProjectile/LineBeam/OrbitingBlades/ThrowGrenade/FieldGenerator/LightningStrike），由 SkillDef SO 驱动 |
| 角色选择 | 无——`PlayerSkills.startingSkill`、`PlayerHealth.maxHp`、`PlayerController.moveSpeed` 全在 Inspector 硬编码 |
| CharacterDefinition | 已有 SO（`Assets/Script/Game/Characters/CharacterDefinition.cs`），含 `characterId/displayName/portrait/startingSkill/maxHpBonus/moveSpeedBonus`，但未被任何代码引用 |

### 技能系统与角色的关系

技能和角色外观完全解耦——技能拥有自己的视觉（LineRenderer、飞刀 Prefab、手雷 Prefab 等），玩家身体不随技能施放而变化。这对角色模块是利好：角色只需决定"启动哪个技能"和"子弹长什么样"，不用动技能内部逻辑。

---

## 设计目标

1. **换皮肤**：切换玩家 Body 的 Sprite，不绑定武器
2. **武器绑定**：皮肤自带武器视觉（Sprite）+ 攻击摆动效果 + 技能覆盖（如刀气波替换默认子弹）
3. **补偿僵硬感**：利用武器 Transform 的位置/旋转微动，在自动攻击时产生摆动反馈
4. **预留扩展**：后续可加背包系统、武器养成、运行时换装

## 数据模型

### WeaponDefinition（新建 SO，`Assets/Script/Game/Characters/WeaponDefinition.cs`）

```
字段：
  weaponId              string          武器ID
  displayName           string          显示名称

  渲染：
  sprite                Sprite          武器贴图
  localPosition         Vector3         静止位置（相对玩家，默认 0.35, 0, 0）
  localRotation         Vector3         静止旋转
  localScale            Vector3         缩放（默认 1,1,1）
  sortingOrderOffset    int             Body SortingOrder + 该值（默认 1）

  攻击摆动（无动画补偿）：
  attackSwingAngle      float (14°)     攻击时武器 Z 轴旋转角度
  attackBobOffset       Vector3         攻击时武器位移 (0.06, 0.02, 0)
  attackSwingDuration   float (0.1s)    摆动时长
  attackRecoverDuration float (0.08s)   回弹时长

  技能覆盖（可选）：
  weaponSkillId         SkillId         覆盖角色 startingSkill
  bulletOverridePrefab  GameObject      覆盖 AutoProjectile 的子弹 Prefab
```

### CharacterDefinition（扩展已有 SO）

```
已有字段（不动）：
  characterId           string
  displayName           string
  portrait              Sprite
  startingSkill         SkillId
  locked                bool

新增字段：
  bodySprite            Sprite          角色身体精灵（替换 Body.SpriteRenderer.sprite）
  defaultWeapon         WeaponDef       初始武器（null = 徒手无武器）

删除字段（已被 attributes 替代）：
  baseAttack            float           从未被战斗系统引用，删除
  baseHp                float           从未被战斗系统引用，删除

  moveSpeedBonus        float           已合并到 attributes.moveSpeed
```

### CharacterAttributes（新建 struct，`Assets/Script/Game/Characters/CharacterAttributes.cs`）

```
[System.Serializable]
public struct CharacterAttributes
{
    [Header("攻击")]
    float attack;            攻击力，作为技能伤害系数（1.0 = 技能表原始伤害）
    float attackSpeedMul;    攻速倍率（1.0 = 不变，0.8 = 快 20%）

    [Header("防御")]
    float maxHp;             最大血量
    float defense;           减伤值：finalDmg = rawDmg × 100/(100+defense)

    [Header("机动")]
    float moveSpeed;         移动速度

    [Header("特殊")]
    float critRate;          暴击率 (0~1，如 0.15 = 15%)
    float critDamageMul;     暴击倍率（默认 2.0 = 双倍伤害）
    int   pierceCount;       穿透数（0=不穿透，子弹命中后不回收可继续飞行）
}
```

## 属性框架

### 数据流

```
CharacterDefinition.attributes (SO，设计师配置)
        │
        ▼
CharacterConfigApplier.Start()  一次写入
        │
        ├──▶ PlayerHealth.maxHp = attributes.maxHp
        ├──▶ PlayerController.moveSpeed = attributes.moveSpeed
        └──▶ PlayerSkills.attackMultiplier = attributes.attack
                │
                ▼
        技能 Tick → 发射子弹/造成伤害
                │
                ▼
        EnemyBase.TakeDamage(rawDamage)
                │
                ├── finalDamage = rawDamage × attackMultiplier   (攻击系数)
                ├── if Random < critRate → finalDamage × critDmgMul  (暴击)
                └── finalDamage = finalDamage × 100/(100+defense)    (减伤)
```

### 为何不用 FlatBuffer

| 维度 | FlatBuffer | ScriptableObject（选用） |
|------|------------|--------------------------|
| 数据量 | 适合千行级表数据 | 5-10 角色 × 10 字段 = 50-100 数据点 |
| 编辑方式 | Excel → 导出 → .bytes | Inspector 直接改，即时生效 |
| 引用资源 | 不支持（只能存 ID） | 可拖拽 Prefab/Sprite/AudioClip |
| 项目先例 | LexiconTable、LevelWave、Monster | CharacterDefinition、WeaponDefinition、SkillDefinitionBase |
| 结论 | 过度设计 | 数据量小、需 Unity 资源引用、沿用现有模式 |

### PlayerHealth 改造

新增 public 方法，删除反射 hack：

```csharp
// 新增
public void SetMaxHp(float value) {
    maxHp = value;
}

// 减伤接入 TakeDamage：
public void TakeDamage(float amount, Transform damageSource, float defense = 0f)
{
    // ... 现有无敌/死亡检查 ...
    
    float finalDmg = defense > 0f 
        ? amount * (100f / (100f + defense)) 
        : amount;
    
    hp -= finalDmg;
    // ...
}
```

### 伤害计算接入点

```
PlayerBullet.Launch(dir, speed, damage, lifetime, skillSource)
  → 子弹携带 rawDamage（技能表 per-level 值）

PlayerBullet.OnTriggerEnter2D(enemy)
  → EnemyBase.TakeDamage(rawDamage, skillSource)
  
EnemyBase.TakeDamage(amount, source)
  → 新逻辑：
      float dmg = amount;
      // 1. 攻击力系数（从 PlayerSkills 获取）
      dmg *= attackMultiplier;
      // 2. 暴击判定（从 CharacterAttributes 获取）
      if (Random.value < critRate) dmg *= critDamageMul;
      // 3. 穿透处理（在子弹层，非此处）
      hp -= dmg;
```

穿透逻辑在 `PlayerBullet.OnHitEnemy()` 中处理：

```csharp
// PlayerBullet 新增字段
private int _pierceRemaining;

public void Launch(..., int pierceCount = 0) {
    _pierceRemaining = pierceCount;
}

protected virtual void OnHitEnemy(GameObject enemy) {
    enemy.GetComponent<EnemyBase>()?.TakeDamage(damage, skillSource);
    
    if (_pierceRemaining > 0) {
        _pierceRemaining--;
        return;  // 不回收，子弹继续飞行
    }
    Release();
}
```

### 暴击视觉反馈

暴击时伤害数字放大/变色，通过 `DamageFloatText` 实现：

```
DamageFloatText.Play(position, amount, isCrit)
  → isCrit 时：字体放大 1.5x、颜色改为金色 #FFD700、显示 "暴击!" 标签
```

## 运行时组件

### CharacterAppearance（新建，`Assets/Script/Game/Player/Components/CharacterAppearance.cs`）

管理 Body + Weapon 的视觉状态：

```
职责：
  - 持有 bodyRenderer 引用（Body 子节点的 SpriteRenderer）
  - 管理 Weapon 子节点（GameObject，动态创建/销毁）
  - 镜像 bodyRenderer.flipX 到 Weapon
  - 播放攻击摆动协程

公开方法：
  ApplySkin(CharacterDefinition def)
    → bodyRenderer.sprite = def.bodySprite

  ApplyWeapon(WeaponDefinition def)
    → 创建/配置 Weapon 子节点
    → 设置 sprite、transform、sortingOrder

  RemoveWeapon()
    → 销毁 Weapon 子节点

  PlayAttackSwing(WeaponDefinition def)
    → 协程：apply attackSwingAngle + attackBobOffset
    → 持续 attackSwingDuration → lerp 恢复 attackRecoverDuration

内部事件驱动：
  OnEnable 订阅 SkillCastEvent
  收到 AutoProjectile 的 SkillCast → PlayAttackSwing()

  LateUpdate 中镜像 bodyRenderer.flipX 到 Weapon.localScale.x
```

Weapon 子节点结构：
```
Player (root)
  Body (已有，SpriteRenderer + PlayerHitFeedback)
  SkillBeamVisuals (已有，LineRenderer 组)
  Weapon (NEW，SpriteRenderer，CharacterAppearance 创建)
```

### CharacterConfigApplier（新建，`Assets/Script/Game/Player/Components/CharacterConfigApplier.cs`）

场景加载时的一次性引导组件：

```
职责：
  - Start() 中读取 SelectedCharacterContext + CharacterCatalog
  - 将 CharacterDefinition 应用到所有子系统

执行顺序（Start 中，PlayerSkills 在 Awake 已完成首次构建）：
  1. PlayerHealth.SetMaxHp(def.attributes.maxHp) → ResetToFull()    ← 干净 API，不再用反射
  2. PlayerController.moveSpeed = def.attributes.moveSpeed
  3. PlayerSkills.attackMultiplier = def.attributes.attack           ← 攻击力系数写入技能上下文
  4. 确定 effectiveStartingSkill（weapon.weaponSkillId ?? def.startingSkill）
  5. PlayerSkills.startingSkill = effectiveStartingSkill
  6. PlayerSkills.RebuildFromStartingSkill()
  7. 遍历 boundSkills，PlayerSkills.TryAddSkill()
  8. CharacterAppearance.ApplySkin(def)
  9. 若 def.defaultWeapon != null → CharacterAppearance.ApplyWeapon(def.defaultWeapon)
  10. 若 weapon.bulletOverridePrefab != null → 覆盖 SkillAutoProjectile.bulletPrefab

字段：
  characterCatalog  CharacterCatalog  Inspector 拖拽赋值
```

## 攻击视觉反馈流程

```
SkillAutoProjectile.Tick()
  → 计算目标方向、生成子弹
  → PublishSkillCast(skillId=AutoProjectile, worldPosition=...)
    ↓ EventBus 同步分发
CharacterAppearance.OnSkillCast(SkillCastEvent e)
  → e.skillId == AutoProjectile ? PlayAttackSwing(_currentWeaponDef)
    ↓ 协程
  武器 transform.rotation.z += attackSwingAngle（持续 0.1s）
  武器 transform.position += attackBobOffset
  lerp 恢复（0.08s）
```

由于无动画资源，所有视觉反馈通过**纯 Transform 计算**实现，零额外资源依赖。

## 将来扩展兼容性

### 背包系统

`WeaponDefinition` SO 已与 `CharacterDefinition` 解耦。背包层只需加一个运行时包装：

```
RuntimeWeapon (class)
  ├─ weaponDef          WeaponDef  引用 SO
  ├─ level / enhance    int        养成数据
  ├─ GetAttackBonus()   float      战力加成
  └─ GetBulletPrefab()  GameObject 可能被强化覆盖的子弹

WeaponInventory (MonoBehaviour)
  ├─ ownedWeapons       List<RuntimeWeapon>
  ├─ equippedWeapon     RuntimeWeapon
  ├─ Equip(weaponId)    → CharacterAppearance.ApplyWeapon(def) + 更新战力
  └─ Unequip()          → CharacterAppearance.RemoveWeapon() + 扣除战力
```

`CharacterAppearance.ApplyWeapon()` 已支持重复调用（先卸旧再装新），与背包系统天然兼容。

### 多武器/双持

扩展 `WeaponDefinition` 或 `CharacterConfigApplier` 支持 `WeaponDefinition[]` 数组，`CharacterAppearance` 改为字典管理多个 Weapon 子节点。当前设计不做，但不必现在埋桩。

## 潜在坑点

| 坑点 | 说明 | 处理方式 |
|------|------|---------|
| PlayerSkills 重复构建 | Awake 先按 Inspector 默认建一次技能，Start 中 RebuildFromStartingSkill 再建一次 | 开销仅场景加载时一次，可接受 |
| 武器 flipX 不同步 | Body flipX 由 PlayerController.LateUpdate 控制，Weapon 是另一帧的 LateUpdate 镜像 | CharacterAppearance.LateUpdate 读 bodyRenderer.flipX，同一帧内保证一致 |
| HitFeedback 只影响 Body | PlayerHitFeedback 在 Body 子节点上，Weapon 不受闪红影响 | 正确行为——武器不应闪红 |
| 未选角色 | SelectedCharacterContext 为空 | GetEffective() 回退到 CharacterCatalog.GetDefault() |
| 技能 Definition 的 bulletPrefab | AutoProjectileSkillDefinition.ApplyStatsToSkill 不覆盖 bulletPrefab | 在 CharacterConfigApplier 中后设，安全 |
| Editor Play 从 Game 场景直接启动 | SelectedCharacterContext 可能残留上次运行的选择 | CharacterConfigApplier 对空选择回退默认角色 |
