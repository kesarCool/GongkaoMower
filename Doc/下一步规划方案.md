## 一、局内 Boss 技能扩充

### 当前：`BossBehavior_T1` 硬编码，只有一种技能

### 目标（沿用已有设计文档）

分两阶段：

**阶段 A：平移现有 Boss 到 BossBrain（1 天）**

创建 `BossBrain` + `BossSkillModule` 基类 + `HomingKnifeModule`，现有 `BossBehavior_T1` 的逻辑平移进去。`Monster` 表加 `element[]` / `elementNum[]` 字段配置技能。

**阶段 B：扩充技能库（2-3 天）**

| 技能 | 表现 | 复杂度 |
|------|------|--------|
| Dash（冲锋） | Boss 蓄力 0.5s → 向玩家方向冲刺 → 路径碰撞伤害 | 低，已有 HomingBullet 可参考 |
| BladeBurst（环形刀气） | Boss 周围生成 8 发刀气，各向飞出 360° | 低，复用 ScatterBullet 逻辑 |
| Zone（地裂） | Boss 拍地，生成 3 条扇形裂缝，延迟 1s 爆发伤害 | 中，需地板预警视觉 |
| Summon（召唤） | Boss 暂停 2s，身边生成 3 个小怪 | 中，需拦截 EnemyAI |
| Clone（分身） | Boss 分出一个 30% 血的镜像 | 高，生命周期复杂 |
| Revive（复活） | Boss 死亡后 3s 满血复活（仅一次） | 高，需拦 Die() |

阶段 A + 前 3 个技能（Dash/BladeBurst/Zone）即可让现有 Boss 从"傻追"升级为"有节奏感的战斗"。

## 二、局外养成系统

### 2.1 英雄解锁

**现状**：`CharacterDefinition.locked` 只是 bool 标记，无任何解锁逻辑

**方案**：

```
解锁方式（可按角色混用）：
  ├─ 默认解锁（奋斗哥）
  ├─ 通关关卡 X（上岸侠，通关 1-5 解锁）
  ├─ 碎片收集（机甲小宝，收集 30 片解锁）
  └─ 总星数达标（茅山道士，累计获得 15 星解锁）

存档字段扩展：
  PlayerSaveData:
    unlockedCharacters[]  (string[])        // 已解锁角色 ID
    characterFragments{}  (dict id→int)     // 角色碎片数
    totalStars            (int)             // 总星数
```

**碎片来源**：
- 通关奖励（每关卡首次通关给 N 片对应角色的碎片）
- 每日挑战（后续可加）
- Boss 击杀掉落

### 2.2 英雄属性升级

**现状**：`CharacterAttributes` 的值是静态 SO，无法局外提升

**方案**：在 `CharacterAttributes` 的基础上新增**可升级维度**

```
HeroUpgradeData (SO 或 JSON)
  ├─ 角色 ID
  ├─ 升级等级 (1-20)
  └─ 每级加成 (乘算叠加到 CharacterAttributes 上)

例如 奋斗哥 Attack Lv.1→Lv.10:
  attackBonus = 1.0 → 1.0 + 9 × 0.05 = 1.45 (+45%)
```

**消耗**：金币（新货币），关卡结算时产出。越高级消耗越高。

**UI**：选角面板已有详情展示，加"升级"按钮 + 简单的进度条。

### 2.3 背包（武器系统）

**现状**：`WeaponDefinition` 已存在（含 bulletOverridePrefab/weaponSkillId），但角色固定绑定一把武器

**方案**：轻量武器背包

```
WeaponInventory (挂在 PlayerProfileService 上)
  ├─ 持有武器列表
  ├─ 装备中的武器（只能装备一把）
  └─ Equip(weaponId) / Unequip()

武器来源：
  ├─ 关卡掉落
  ├─ Boss 掉落
  └─ 商店购买（后续）

武器差异化：
  ├─ 子弹外观（已有 bulletOverridePrefab）
  ├─ 技能加成（武器自带被动属性，如 attack+10%）
  └─ 稀有度（普通/稀有/传说，影响加成数值）
```

**已有基建**：`CharacterAppearance.ApplyWeapon()` 支持运行时换武器，无需大改。

## 三、推荐实施顺序

| 优先级 | 模块 | 工期 | 理由 |
|--------|------|------|------|
| **P0** | Boss 阶段 A（平移）| 1d | 消除硬编码，为后续 Boss 技能铺路 |
| **P1** | 英雄解锁（关卡解锁）| 1d | 回馈通关进度，立刻有"局外成长感" |
| **P1** | Boss 阶段 B 前 3 技能 | 2d | Dash+刀气+地裂，立竿见影的战斗丰富度 |
| **P2** | 英雄属性升级 + 金币 | 2d | 需新建货币系统 + UI + 存档 |
| **P2** | 背包/武器 | 2d | WeaponInventory + 武器掉落 |
| **P3** | 碎片解锁 + 总星解锁 | 1d | 已有关卡解锁后补充 |
| **P3** | Boss 召唤/分身/复活 | 2d | 复杂，可后再议 |

## 四、风险与坑点

| # | 风险 | 应对 |
|---|------|------|
| 1 | 金币系统无美术/UI | 先用文字计数器，后续补美术 |
| 2 | 武器掉落需关卡波次配置 | 在 `LevelWave` 表中加 `dropWeaponId` 字段 |
| 3 | 角色升级与局内被动叠加 | 确保升级加成写在 `CharacterConfigApplier` 中，在被动技能之后叠加——乘法链路清晰 |
| 4 | `PlayerSaveData` 版本兼容 | 新增字段默认值兜底，旧存档不崩 |
| 5 | BossBrain 与已有爆破刀存在 Bug | 只在 T1 Boss 上测试通过后再替换 |
