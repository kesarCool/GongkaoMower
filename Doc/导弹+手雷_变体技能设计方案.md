# 导弹 + 手雷 变体技能设计方案

日期: 2026-06-01

---

## 一、变体系统回顾

已有模式（AutoProjectile 家族）：

| SkillId | 名称 | SkillFamily | 定位 | 专属角色 |
|---------|------|-------------|------|---------|
| 1 | 弹无虚发 | AutoProjectile(1) | 基础版，卡池通用 | 无 |
| 7 | 百步穿杨 | AutoProjectile(1) | 手枪版，均衡 | 奋斗哥 |
| 8 | 万刃齐发 | AutoProjectile(1) | 飞刀版，弹幕 | 上岸侠 |
| 9 | 天师符令 | AutoProjectile(1) | 符箓版，高伤 | 茅山道士 |

规则：`SkillFamily = AutoProjectile` 的四个技能在卡池中互斥——角色主技能是哪个，卡池就只出哪个。没装备 AP 技能的角色只出基础版。

## 二、导弹变体

### 2.1 技能定义

| SkillId | 名称 | SkillFamily | 定位 |
|---------|------|-------------|------|
| 10 | 东风快递 | HomingMissile(10) | 专属版，6 发连射，AOE 爆炸 |
| 11 | 追踪弹 | HomingMissile(10) | 基础版，1 发，小型 AOE |

### 2.2 基础版 vs 专属版

| 属性 | 追踪弹(11) | 东风快递(10) |
|------|-----------|------------|
| 弹数 Lv1-5 | 1, 1, 2, 2, 2 | 2, 3, 4, 5, 6 |
| 最大目标 | 1 | 2, 3, 3, 4, 5 |
| CD | 3.0→2.0s | 2.0→1.2s |
| 伤害倍率 | 1.0→1.5 | 1.0→1.75 |
| AOE 半径 | 0.8→1.0 | 1.2→1.7 |
| 导弹速度 | 6 | 8 |
| 追踪转向 | 90°/s | 180°/s |
| 卡池出现 | 角色无导弹技能时开放 | 仅机甲小宝 |

### 2.3 共享实现

- 基础版和专属版共用 `SkillHomingMissile` 运行时类
- 共用 `HomingMissileBullet` 弹丸类
- `SkillFamily = HomingMissile(10)`，互斥规则与 AutoProjectile 一致

## 三、手雷变体

### 3.1 技能定义

| SkillId | 名称 | SkillFamily | 定位 |
|---------|------|-------------|------|
| 4 | 天降正义 | ThrowGrenade(4) | 基础版，抛物线单爆 |
| 12 | 弹射雷 | ThrowGrenade(4) | 专属版，命中后弹射再爆，最多 N 次 |

### 3.2 弹射雷设计

```
投掷 → 落地 → 爆炸 AOE
              → 弹射到附近随机敌人位置
              → 再爆
              → 再弹射（最多 N 次）
```

| 属性 | 天降正义(4) | 弹射雷(12) |
|------|-----------|----------|
| 弹射次数 | 0 | 1→3（per-level） |
| CD | 2.0→1.0s | 2.5→1.5s |
| AOE 半径 | 1.5→2.0 | 1.2→1.5 |
| 伤害倍率 | 1.0→1.75 | 1.0→1.5 |
| 卡池出现 | 角色无手雷技能时开放 | 仅专属角色 |

### 3.3 弹射实现

`GrenadeProjectile` 新增子类 `BouncingGrenade`：
- 爆炸后不立即回收，查找范围内最近敌人
- 计算抛物线弹道飞向下一个目标
- 弹射次数用完 → 最终爆炸 → 回收

## 四、SkillId 规划

```
HomingMissile(10) — 机甲小宝专属     SkillFamily = HomingMissile(10)
HomingMissileBasic(11) — 基础版       SkillFamily = HomingMissile(10)
BouncingGrenade(12) — 专属弹射雷      SkillFamily = ThrowGrenade(4)
```

现有 `ThrowGrenade(4)` 保留为基础版。

---

## 五、家族互斥规则（无需改动）

已有 `CardDeck` 家族互斥逻辑自动生效：

- 机甲小宝 → 只出专属版(10)，不出基础版(11)
- 其他角色 → 只出基础版(11)，不出专属版(10)
- 专属手雷角色 → 只出弹射雷(12)，不出基础版(4)
- 熊猫侠 → 基础版(4)，不出弹射雷(12)
