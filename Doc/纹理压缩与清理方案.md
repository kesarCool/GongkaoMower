# 纹理压缩与未使用资源清理方案

## 第一步：自动分析（一键）

Unity 菜单 → `Tools/纹理优化分析`

生成 `texture_report.txt` 在项目根目录，包含三类清单：

| 分类 | 说明 | 操作 |
|------|------|------|
| 未使用纹理 | 没有任何 Prefab/场景引用 | **直接删** |
| 使用中但过大 | >50KB，需压缩 | 按第二步批量压缩 |
| 使用中小纹理 | <50KB | 跳过 |

---

## 第二步：批量压缩大纹理

根据报告里的"需压缩"清单，逐个选中纹理文件（在 Project 窗口 Ctrl+点击多选），然后在 Inspector 中统一设置：

### 特效纹理（爆炸、冲击、光束）

**大纹理**（>500KB，如 GRENADE EXPLOSION.png 3.2M）：
```
Texture Type:        Sprite (2D and UI)
Max Size:            1024           ← 4K→1K，视觉效果损失很小
Compression:         RGBA Crunched ETC2
Use Crunch Compression: ✔
Crunch Quality:      50
Generate Mip Maps:   ✘
Filter Mode:         Bilinear
```

**中纹理**（50K-500KB）：
```
Max Size:            512 或 1024（看情况）
Compression:         RGBA Crunched ETC2
其余同上
```

### UI 纹理（按钮、背景、图标）

```
Texture Type:        Sprite (2D and UI)
Max Size:            512（按钮）/ 1024（背景）
Compression:         RGBA Crunched ETC2  ← 无透明通道的可选 RGB Crunched ETC2
Use Crunch Compression: ✔
Crunch Quality:      50
Generate Mip Maps:   ✘
Filter Mode:         Bilinear
```

### 地图瓦片（GeneratedTiles）

```
Texture Type:        Sprite (2D and UI)
Max Size:            64             ← 32px 瓦片，64 够用
Compression:         Uncompressed   ← 太小了，压缩反而变大
Generate Mip Maps:   ✘
Filter Mode:         Point (no filter)
```

---

## 第三步：清理未使用文件

根据报告中的"未使用纹理"清单，在 Project 窗口中导航到对应路径，删除文件。

**但是**，有一些文件虽然在引用链上断了，但你后续可能用到。判断标准：

| 文件 | 建议 |
|------|------|
| `Effect/_Effect/` 下的噪音纹理（noise_*.png） | 如果 `Effect_58Link.prefab` 在用 → 保留，否则整目录删 |
| `hero-*.png`（角色头像） | 如果选角/UI 没用 → 删 |
| `1001.png`, `1004.png` 等 | 如果选关界面没用 → 删 |
| `D_cheng/hong/lv.png` | 等级标识，看 UI 是否引用 |
| `icon_*.png`（Sprte Assets） | 技能栏图标，可能通过 Sprite Asset 引用，报告会检查 |

---

## 第四步：重建并验证

1. 删完未用文件 → 重新 Build WebGL
2. 检查 `Build/webgl/webgl.data` 是否变小
3. 微信开发者工具跑一遍，确认没有紫色 Missing 贴图

## 常见问题

### Q: Crunched 压缩后纹理模糊了？
A: Crunch Quality 调高到 70-80，或者改用不 Crunched 的 ETC2/RGBA Compressed。模糊通常发生在小尺寸纹理上，512 以上不太明显。

### Q: 微信小游戏不支持 ETC2？
A: 支持。ETC2 是 OpenGL ES 3.0 标准，微信小游戏 WebGL 底层用 ETC2。如果担心兼容性可改用 ASTC 6×6（更好但构建慢）。

### Q: 删错了资源，编译报错怎么办？
A: Ctrl+Z 恢复文件，重新导入。或者从 git 回退。

### Q: 报告中"引用检测"会漏吗？
A: 会。以下引用方式检测不到：
- 代码中 `Resources.Load("xxx")` 动态加载
- `Addressables` 引用
- 字符串拼接路径加载

所以删除前在 Project 窗口右键文件 → `Find References In Scene` 二次确认。
