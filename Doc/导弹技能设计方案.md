# 导弹技能设计方案 — 机甲小宝主技能

日期: 2026-06-01

---

## 一、技能定位

**技能名**：待定（参考：万箭齐发 / 弹幕风暴 / 导弹雨）

**角色**：机甲小宝（character_03），替换现有 LineBeam 主技能

**玩法定位**：中远程大面积火力覆盖，CD 型爆发输出。攻击方式=**锁定目标后连发导弹 → 追踪飞行 → 命中爆炸 AOE**。

**爽感关键词**：追踪、连发、多枚齐射、爆炸、屏幕震动。

---

## 二、运行时表现

### 2.1 完整攻击循环

```
CD 到 → 锁定范围内所有敌人（最多 N 个）
     → 每个目标发射 1 枚追踪导弹（导弹数量 = min(N, maxTargets)）
     → 导弹以弧线加速飞向各自目标
     → 命中目标 → 圆形 AOE 爆炸（半径 R）
     → 爆炸伤害 + 爆炸特效 + 震屏微颤
     → 进入 CD
```

### 2.2 视觉要素

| 要素 | 实现方式 |
|------|---------|
| 导弹本体 | 池化 GameObject，挂 `HomingMissileBullet`（继承 PlayerBullet） |
| 尾迹 | 子物体 TrailRenderer，导弹创建时激活 |
| 引擎火焰 | 子物体粒子系统（可选，后续加） |
| 爆炸 | `CombatVfxSpawner.TryPlayPooled(explosionFxPrefab)` |
| 震屏 | `EventBus` 发布震屏事件（新事件或复用 SkillCastEvent） |

### 2.3 导弹运动

导弹采用**渐进追踪**——不是瞬间指向目标，而是每帧以有限角速度转向：

```
每帧：
  1. 计算导弹→目标的向量
  2. 当前朝向向目标向量旋转（最多 turnRate °/秒）
  3. 向前移动（speed × dt）
  4. 撞到敌人 → 爆炸 → 回池
  5. 飞行超过 lifetime → 自爆 → 回池
```

与现有 `HomingBullet`（Boss 用）逻辑相同，可直接继承复用。

### 3.3 SkillHomingMissile（运行时）

```csharp
public class SkillHomingMissile : SkillBase
{
    // 从 Definition 写入
    public GameObject missilePrefab;
    public float missileSpeed;
    public float turnRate;
    public float missileLifetime;
    public GameObject explosionFxPrefab;
    public float cooldown;
    public float damage;
    public int salvoCount;
    public int maxTargets;
    public float aoeRadius;

    private float _timer;

    // Tick:
    //   _timer += dt
    //   if _timer < cooldown → return
    //   收集范围内敌人（CombatTargetRegistry），按距离排序
    //   for i in 0..min(salvoCount, 敌人数):
    //       每 0.15s 发射一发（连发间隔）
    //       创建导弹 → Launch(target)
    //   每发导弹发射时有 0.15s 间隔（通过 _salvoTimer 控制）
}
```

### 3.4 HomingMissileBullet

```csharp
public class HomingMissileBullet : PlayerBullet
{
    public float turnRate = 180f;
    public float explosionRadius = 1.5f;
    public GameObject explosionFxPrefab;

    private Transform _target;

    // Launch(target, speed, damage, lifetime, aoeRadius, ...)
    // FixedUpdate:
    //   追踪目标（如果没有或目标死亡，继续直线飞行或找最近敌人）
    //   撞到敌人 → Explode() → AOE 伤害
    //   撞到墙 / 超时 → 自爆（可选）

    void Explode() {
        CombatVfxSpawner.TryPlayPooled(explosionFxPrefab, pos);
        // AOE: Physics2D.OverlapCircle(center, radius)
        //   对范围内所有敌人造成伤害（与 GrenadeProjectile.ApplyAoeDamage 一致）
        // 震屏事件
        Release();
    }
}
```

## 四、视觉表现设计

### 4.1 导弹 Prefab 结构

```
HomingMissile (GameObject, Rigidbody2D, HomingMissileBullet)
  ├── Sprite (SpriteRenderer, 导弹贴图，朝飞行方向旋转)
  ├── Trail (TrailRenderer, 烟雾/火焰拖尾)
  └── EngineFlame (可选粒子系统)
```

### 4.2 导弹发射表现

- 导弹从角色**侧面/头顶**生成（不在角色中心），模拟发射井/肩部发射
- 发射时角色有微小的**后坐力回弹**（0.05s scale punch）
- 连发时每 0.12~0.15s 发射一枚，产生"哒哒哒"连续出弹的节奏感

### 4.3 爆炸表现

- 复用 `CombatVfxSpawner` 爆炸特效
- AOE 伤害圈用 `SkillFieldGenerator` 式的 OverlapCircle
- 震屏：发布新事件 `CameraShakeEvent { intensity, duration }`

### 4.4 音效

- 发射音：低沉机械音 / 引擎轰鸣
- 命中音：爆炸冲击音
- CD 完成提示音（可选）

## 八、潜在坑点

| # | 坑点 | 说明 |
|---|------|------|
| 1 | 导弹追踪性能 | 每帧 `FindNearestEnemy` 或缓存目标引用。目标死亡后导弹需换目标或自爆 |
| 2 | 导弹与现有弹丸池冲突 | 建议新 SpawnLimiter Key `"Missile"`，不与 `"Bullet"` 争上限 |
| 3 | AOE 与 GrenadeProjectile 重复逻辑 | 抽取公共 `AoeUtil` 或复用 GrenadeProjectile 的静态方法 |
| 4 | TrailRenderer 池化 | Trail 需在池回收时 `Clear()`，否则复用时会残留上一轮的拖尾 |
| 5 | 震屏无现有机制 | 需新建 `CameraShakeEvent` 或复用 SkillCastEvent+额外参数 |
| 6 | 连发间隔与 CD 竞争 | `_salvoTimer` 需独立于 `_cooldownTimer`，且整个连发周期会计入 CD 内 |

## 九、实施顺序

1. `SkillId.HomingMissile = 10`

3. `SkillHomingMissile` 运行时 + `HomingMissileSkillDefinition` SO
4. 创建 Prefab（导弹+Trail+爆炸特效）
5. 配置 `.asset`（per-level 数据 + bondedPassiveId）
6. 音效接入
7. 机甲小宝 `startingSkill` 改为 HomingMissile
8. 震屏效果（后续优化）
