## 一、攻击范围系统

### 1.1 数据流

```
CharacterAttributes.attackRangeMul (SO, 默认 1.0)
  → CharacterConfigApplier → PlayerSkills.attackRangeMul
    → 每个主动技能 Tick 中: effectiveRange = baseRange * attackRangeMul
```

### 1.2 改动清单

| 文件 | 改动 |
|------|------|
| `CharacterAttributes.cs` | 新增 `float attackRangeMul = 1f` |
| `CharacterConfigApplier.cs` | `_playerSkills.attackRangeMul = attr.attackRangeMul` |
| `PlayerSkills.cs` | 新增 `public float attackRangeMul = 1f` |
| `SkillId.cs` | 新增 `PassiveAttackRange = 107` |
| `PassiveSkillRegistry.cs` | case 107 → 读写 `PlayerSkills.attackRangeMul` |
| `PassiveSkillDefinition` SO | 创建 `SkillDef_PassiveAttackRange.asset` |

### 1.3 各技能接入

| 技能 | 基准字段 | 接入位置 | 改动 |
|------|---------|---------|------|
| AutoProjectile | `FindNearestEnemy(maxRange=9999)` | 不需要——已经搜全图 | 不改 |
| HomingMissile | `maxRange` | `Tick()` 收集目标前 | `float r = maxRange * GetPlayerSkills()?.attackRangeMul ?? 1f` |
| LineBeam | `beamLength` | `Tick()` 射线发射前 | 同上 |
| ThrowGrenade | `maxTargetRange` | `Tick()` 搜敌前 | 同上 |
| FieldGenerator | `radius` | `Tick()` 中 `ApplyDamageInRadius` | 同上 |
| LightningStrike | `maxRange` | `Tick()` 搜敌前 | 同上 |
| OrbitingBlades | `orbitRadius` | `Tick()` 轨道半径 | 见第二章 |

## 二、OrbitingBlades 改版——视觉同步

### 2.1 当前行为

```
Tick() 每帧:
  _angle += rotateSpeedDeg * dt
  _orbitRoot.rotation = 绕轴旋转

SkillOrbBladeHit.OnTriggerStay2D():
  每个敌人独立计时
  Time.time >= _nextTick → 扣血，_nextTick = Time.time + 0.15s
```

问题：4 把刀 × N 个敌人 = 4N 个独立定时器，刀划过敌人可能刚好不在 tick 窗口内 → 无视。

### 2.2 改版目标

- 刀刃划过敌人就产生伤害（取消 tickInterval 错觉）
- 无敌人时刀刃收缩/隐退
- 有敌人时刀刃展开并造成连续伤害
- 攻击范围加成影响轨道大小

### 2.3 方案：每帧累加 + 视觉同步

```
SkillOrbBladeHit.OnTriggerStay2D():
  ── 改为每敌每帧累加 deltaTime ──
  每帧：对每个触发体累加 dt
  累积 >= 0.06s → 扣 damagePerTick，accum -= 0.06s
  （0.06s = 16FPS，肉眼感觉连续；频率 = 每秒 ~16 次，每次扣 damagePerTick * 0.06）
```

实际伤害 = `damagePerTick * (dt / tickInterval)` 转换为连续伤害：
```
每帧: eb.TakeDamage(damagePerTick * (dt / Mathf.Max(0.05f, tickInterval)), ...)
```

这样不需要累积器，也不需 per-enemy 状态——每帧直接按时间比例扣血。

### 2.4 刀刃显隐

```
无敌人触发 OnTriggerStay2D 持续 0.8s:
  → 轨道半径缩小为原来的 0.3 倍（收拢）
  → SpriteRenderer alpha 渐降为 0.3（半透明）

有敌人触发:
  → 轨道立即展开为 attackRangeMul * orbitRadius
  → alpha 立即恢复为 1.0
```

实现方式：在 `SkillOrbitingBlades.Tick()` 中追踪 `_timeSinceLastHit`，每帧检查。

### 2.5 冲突分析：攻击范围 × OrbitRadius

```
无冲突。

orbitRadius   = 定义值（如 1.2）
attackRangeMul = 攻击范围加成（如 1.3）

生效半径 = orbitRadius * attackRangeMul

每帧 Tick: orbitRoot.localScale = attackRangeMul（缩放整组刀刃）
          攻击范围加成只改变缩放，不改 orbitRadius 字段值
          刀片位置由 orbitRadius * stepAngle 决定，在局部空间内不变
          缩放由 _orbitRoot.localScale = Vector3.one * attackRangeMul 统一控制
```

这样 `RebuildBlades()` 只在 bladeCount 变时才重建，attackRangeMul 变化只需改一次 transform scale，不需要销毁重建刀刃。

### 2.6 改动点汇总（OrbitingBlades 部分）

| 文件 | 改动 |
|------|------|
| `SkillOrbitingBlades.cs` | 新增 `_timeSinceLastHit`；Tick 中加显隐逻辑 + attackRange 缩放；OnEquip 中读取 `PlayerSkills.attackRangeMul` |
| `SkillOrbBladeHit.cs` | 重写 `OnTriggerStay2D`：取消 `_nextTick` 定时器，改为每帧 `dt/tickInterval * damagePerTick` 比例扣血 |
| `OrbitingBladesSkillDefinition.cs` | 不变 |

### 2.7 伪代码（OrbitingBlades.Tick 改版）

```csharp
public override void Tick(float deltaTime)
{
    if (!_equipped || _ctx.player == null) return;
    if (_orbitRoot == null) return;

    // 检查攻击范围加成
    var ps = GetPlayerSkills();
    float rangeMul = ps != null ? ps.attackRangeMul : 1f;

    // 旋转
    _angle += rotateSpeedDeg * deltaTime;
    _orbitRoot.rotation = Quaternion.Euler(0f, 0f, _angle);
    _orbitRoot.localScale = Vector3.one * rangeMul;

    // 显隐
    bool anyHit = CheckAnyBladeHit(); // 遍历 _activeBlades 的 hit 组件问是否有活跃碰撞
    _timeSinceLastHit = anyHit ? 0f : _timeSinceLastHit + deltaTime;

    float targetAlpha = _timeSinceLastHit > 0.8f ? 0.3f : 1f;
    SmoothAlpha(targetAlpha, deltaTime);
}
```

## 三、实施顺序

1. **攻击范围**：加字段 + 各技能接入（不影响现有逻辑，纯扩展）
2. **OrbitingBlades 改版**：独立改动，不依赖攻击范围
3. **Optional**：新增 `PassiveAttackRange(107)` 被动技能 SO

两者无冲突，orbitRadius 和攻击范围用 `_orbitRoot.localScale` 隔离，互不污染。

## 四、潜在风险

| # | 风险 | 缓解 |
|---|------|------|
| 1 | 连续伤害 DPS 与旧 tick 伤害不等 | `damagePerTick * dt / tickInterval` 保持数学等价 |
| 2 | 每帧 TakeDamage 产生大量 DamageFloatText | `EnemyBase.TakeDamage` 已经做 dedup；飘字在 EnemyDamagedEvent → DamageFloatText 中每 0.15s 才出一次（由原有 minInterval 控制） |
| 3 | `_orbitRoot.localScale` 影响刀片之外 | _orbitRoot 下只挂刀片子物体，无其他元素 |
| 4 | 范围加成 × orbitRadius 乘积过大 | `attackRangeMul` 默认 1.0，被动加成最多 ~2.3 倍，刀刃半径可控 |
