# 技能卡数值与机制文案

卡片的主数值和描述区均读取技能定义中的配置。`description` 与 `levelDescriptions` 只填写机制、操作方式或特色，不再覆盖自动生成的数值说明。

- `GetLevelDescriptionLine(level)` 显示该级实际数值，并追加该级机制文案。第一级没有专属机制文案时使用 `description`。
- `GetLevelUpgradeDescription(from, to)` 对比前后两级，只列出变化的配置；没有数值变化时显示目标等级数值。机制文案独立追加。
- 伤害倍率用攻击力百分比显示，例如 `1.25` 显示为 `125%攻击力`。升级增幅以当前倍率为基数计算。
- 罡气护体分别展示跳伤间隔、每次跳伤和每秒总伤害；单次跳伤由每秒倍率乘以结算间隔得到，不能将每秒倍率解释为每跳倍率。这三项在升级时显示前后实际值。
- 射速增幅按攻击间隔的倒数计算，例如 `0.85秒 → 0.8秒` 对应 `射速+6.25%`。冷却、范围等以实际数值和单位展示前后变化。
- 被动根据加成类型区分百分比与绝对数值；回血明确表示最大血量比例。
- 满级的爆发数量、爆发冷却、射线变体数量和触发间隔同样取配置。不要在机制文案中写死这些数量。

`SkillDescriptionStat` 统一处理单位、精度与升级对比。各技能的 `GetDescriptionStats` 使用与技能运行时相同的配置字段和等级访问器。新增技能类型时必须实现此方法，避免又引入手写数值来源。

原有伤害、射速和数量文案已清理；“子弹分裂”“环绕爆发”等机制保留。技能的战斗参数、预制体引用和解锁关系没有调整。迁移前备份位于 `Library/SkillDescriptionMigration/Before/`，数值验证记录位于 `Library/SkillDescriptionMigration/checks.json`。
