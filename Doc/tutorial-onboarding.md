# 首版新手引导

入口自动接入，无需给现有场景或预制体手动挂组件。提示框沿用大厅的奶油色、棕色描边、金色按钮，手指使用 UGUI 网格绘制。没有引入旧项目的网络、资源加载器、Shader 或单例。

登录入口统一为 `Boot → Login → Home`，移除首次玩家跳过大厅直达战斗的旧分支。新玩家先看到大厅开始按钮指引，主动点击后才进入 `BattleLoading → Game`。`GameUnlockSkill` 原有的首关「操作指引」弹窗已移除，101 的起始技能仍正常解锁，不重复弹技能介绍。

后续关卡的「技能解锁」介绍保留，等待 Loading、移动/自动攻击引导、选卡及其它弹窗结束后串行显示。提示确认后才记为已读；若被选卡替换，则在界面空闲后重试，避免覆盖新引导或卡在丢失的回调上。提示关闭仅释放自己的暂停锁，不提前恢复选卡暂停；切场景或组件禁用时清理自己持有的提示。技能是否解锁仍由卡池进度决定，提示排队不影响实际解锁。

## 流程

| 阶段 | 触发 | 完成依据 |
| --- | --- | --- |
| 开始挑战 `start_battle` | 首次进入 Home | 关卡校验通过，实际发起 BattleLoading |
| 移动 `move` | Game 的战斗协调器 Start | 有移动输入时，角色实际累计移动至少 0.8 世界单位；忽略入场锁定和单帧大位移 |
| 自动攻击说明 `auto_attack` | 移动指引结束 | 点击「继续战斗」；说明期间申请 UIManager 暂停锁 |
| 三选一 `select_skill` | 首次显示真实技能选择面板 | 真实选卡回调成功添加或升级技能；任意一张卡均可选择 |
| 角色页 `character_tab` | 首次结算后返回 Home | 用户切换到角色页 |
| 角色升级 `upgrade_hero` | 角色页指引完成 | `HeroLevelUpEvent`，只有实际扣金币、升级成功才记为完成 |

最后两个步骤属于界面显示的第 05 阶段。金币不足或达到等级上限时改为说明框，可点「知道了」放行，并记录为跳过该步。

选卡时手指优先指向从左到右的第一张主动技能卡；没有主动卡时指向中间卡。三张卡始终都可选择，刷新后重新定位。移动示意使用横向“8”字轨迹，手指沿轨迹循环，整体放在人物下方并随屏幕投影避让人物。

新增条件步骤 `bonded_passive`：选卡中首次出现带「突破组合」的羁绊被动卡时，显示「获得对应的羁绊被动，才能突破技能。获得后，继续升级关联主动技能即可突破。」手指指向该被动卡，所有卡牌仍可选择。点「知道了」或确认选择任意卡后立即存档为已了解，不重复提示；确认记录发生在选卡动画之前，不依赖动画结束时提示是否仍显示，也不要求选中被动卡。若首次选卡同时触发，先说明羁绊，再显示基础选卡提示。基础选卡已完成的账号也能在后续首次遇到羁绊被动时看到提示，整套引导已跳过的账号继续尊重跳过选择。刷新后不再有羁绊卡时关闭提示，单独刷新不记录完成；同一面板随后确认选卡仍会记录此前已显示的说明。此步骤使用「进阶指引」标签，独立于首轮五阶段编号。

## 退出和容错

- 右上角「跳过引导」立即关闭整套新手引导并持久化选择，不关闭业务面板、不奖励金币、不模拟点击、不记录为完成。
- 目标未出现、不可点击或移出屏幕时，最多等待 8 秒，期间不遮挡界面；超时单独记录该步已跳过。
- 单步显示最多 45 秒，超时释放遮罩、触摸拦截和该引导持有的暂停锁；控制器有独立看门狗兜底。
- 其它弹窗打开、目标失效、玩家死亡、切换/卸载场景、应用暂停、控制器禁用或销毁时关闭表现，不把中断当成完成。
- 选卡时跳过仅关闭指引，保留选卡面板及其暂停；升级引导不替用户消费。
- 提示框、跳过按钮均拦截原始触摸，避免 Legacy Input 在 UGUI 之外误触移动。关闭后留 0.15 秒输入缓冲。
- 动画、显示计时和等待使用非缩放时间；高亮每帧重新投影目标，支持 Overlay/Camera Canvas、CanvasScaler、屏幕安全区和微信胶囊避让。
- 奖励展示队列在引导显示时等待，其它确认框和业务弹窗仍可优先打开。

## 存档

`PlayerSaveData` 升至 v6，新增 `tutorial`。`completed`、`skippedSteps`、整套 `skipped` 分开记录，另有 `battleSettled` 用于回大厅后的升级提示。旧版本已有通关记录的玩家自动免于本次新手引导；没有通关记录的账号仍可进入。没有改动其它存档内容。

编辑器菜单：`工具 → 新手引导 → 重置引导进度（保留角色与货币）`。仅重置引导数据，下次进入大厅生效，方便现有账号验收。

## 验证

菜单 `工具 → Home UI → Preview Tutorial` 自动运行真实 Home/Game 场景与实际移动、选卡、升级处理器，使用内存存档，不改动玩家的持久化存档。结果写入 `ArtOutput/UI/Tutorial/validation-report.json`，截图同目录。

使用 `工具 → Home UI → Finish Preview` 退出并恢复原先的场景与 Game View 尺寸。验证覆盖 1080×1920、1080×1440、1080×2400、360×640 以及模拟微信胶囊区域；尚需微信真机触摸、前后台切换与平台构建验收。
