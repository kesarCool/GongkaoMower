## 四、数据流总览

```
CharacterDefinition.attributes (SO)
  → CharacterConfigApplier.Start()
    → PlayerHealth.SetMaxHp/SetDefense
    → PlayerController.moveSpeed
    → PlayerSkills.attackMultiplier/critRate/critDmgMul/pierceCount/pierceRate
      → SkillBase.GetFinalDamage() × crit × pierce
        → SkillAutoProjectile/LineBeam/FieldGenerator/etc.Tick()
          → EnemyBase.TakeDamage(..., isCrit)
            → BattleRunMetrics.AddSkillDamage
            → EnemyDamagedEvent(isCrit) → DamageFloatText
```

```
CardDeck.Draw(currentLevel, playerSkills)
  → progression.IsUnlocked (全局持久化)
  → 家族互斥
  → 双槽判断 (主动/被动)
  → GetEffectiveMaxLevel (羁绊满级)
  → CardSelectionSystem.ApplyCard
    → TryAddPassive/TryLevelUpPassive (被动)
    → TryAddSkill/TryLevelUp (主动)
  → CardSelectionPanel.RefreshSkillSlots
    → 主动 5 槽 + 被动 5 槽 HUD
  → CardView.RefreshBondedIcons
    → 被动卡羁绊 icon + 闪烁
```
