## 今日完成

### 1. 中文字体方案定型

经过多轮真机验证，确定以下方案：

| 文字类型 | 字体来源 | 渲染方式 | 覆盖范围 |
|----------|----------|----------|----------|
| 局内敌人文字 | `Resources/Fonts/msyh SDF.asset`（7.2MB） | TMP SDF | EnemyWordLabel |
| UI 层文字 | `Resources/Fonts/msyh SDF.asset`（复用） | TMP SDF | Login/Home/所有场景 |

- `BattleChineseFontRuntime` 新增 `ApplyToTMP(TMP_Text)` 方法 + `TMPChineseFontAutoApply` 组件
- 废弃 `WXUIFontLoader.cs`（`WX.GetWxFont()` 在开发工具/真机环境不一致）

### 2. UI Text → TMP 批量转换工具

创建 `Assets/Editor/ConvertTextToTMP.cs`：
- 菜单：**Tools → 批量转换 Text 到 TMP**
- 自动将场景和预制体中的 `UnityEngine.UI.Text` → `TextMeshProUGUI`
- 保留文字内容、颜色、字号、对齐方式等属性

### 3. SDK 桥接桩

`Assets/WX-WASM-SDK-V2/Runtime/Plugins/SDK-WX-Bridge-Fix.jslib`：
- 提供缺失的 JS 函数桩（`SetUnityUIType`、`WXHideLoadingPage`、`WXGetFontRawData`、`WXShareFontBuffer`）
- 防止 SDK DLL 调用未注册 JS 函数导致 WASM abort

## 构建配置（MiniGameConfig.asset）

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `assetLoadType` | 1 | 子包模式（无 CDN） |
| `compressDataPackage` | 1 | Brotli 压缩数据包 |
| `ScriptOnly` | 1 | WASM 代码分包 |
| `Il2CppOptimizeSize` | 1 | IL2CPP 体积优化 |
| `PreloadWXFont` | 1 | 预加载微信系统字体 |
| `DevelopBuild` | 1 | 开发模式（正式需关闭） |
| `CleanBuild` | 0 | 增量构建 |
